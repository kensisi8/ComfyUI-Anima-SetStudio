# ComfyUI-Anima-SetStudio

ComfyUI 上で **Anima モデル** を使ってキャラクターイラスト集を効率よく作成するためのカスタム拡張機能です。
[Comfyui-Anima-Tools](https://github.com/nregret/Comfyui-Anima-Tools) の **`Anima Multi LoRA Loader`** と **`Anima Prompt Plus`** と同じ使用感・全機能を保ったまま、以下を実現します。

## 主な機能

### 1. LoRA / プロンプトセット管理
- `LoRAリスト`（サムネ・ON/OFF・強度スライダー・トリガーコピー・本家 `LoRA Manager` ポップアップ）と `カテゴリ別プロンプト`（自由なカテゴリ名・ドラッグ並替・一時無効化・実行時ランダム・本家 `Select` ポップアップ）を **1つのセット** として名前を付けて保存・複製・削除できます。
- **画像からのセット読み取り（インポート）**: セット管理画面に生成画像（PNG / WebP / JPEG）をドラッグ＆ドロップまたは選択すると、埋め込みメタデータから **カテゴリ別プロンプト** と **LoRAリスト** を自動抽出してセット編集欄へ取り込めます。
  - `ComfyUI`（`Anima Prompt Plus` / `Anima*Selector` / `Anima Multi LoRA Loader` / `LoraLoader` / `Power Lora Loader` / `CLIPTextEncode`）および `WebUI (A1111)` の `parameters` 形式に対応。
  - 単一テキストプロンプトの画像も自動でカテゴリ分け（`品質`・`画師`・`キャラ`・`体格`・`衣装`・`ポーズ`・`背景`・`その他`）され、ボタン1つで「1枠のまま」と切り替えられます。
- **セットごとのアスペクト比設定**: セット編集画面でセットごとにアスペクト比（`共通設定のまま` / `2:3` / `3:4` / `4:5` / `9:16` / `1:1` / `4:3` / `3:2` / `16:9` / カスタム比率）を指定できます。イラスト集作成画面で選ぶ「生成サイズ感（基準解像度：`ラフ 768` / `標準 1024` / `高画質 1216` / `特大 1408`）」の総ピクセル数を保ったまま、各セットのアスペクト比に合わせて16の倍数へ自動計算します（画像インポート時は元画像の縦横比も自動検出）。
- **セットごとの共通プロンプト無効カテゴリ設定**: セット編集画面（および呼び出し済みカードの一時編集）で「このセットで無効にする共通プロンプトのカテゴリ」を指定すると、そのセットを生成する時だけ該当カテゴリの共通プロンプトを除外できます（イラスト集作成画面の「使わないカテゴリ（セット側除外）」とは独立して動作します）。
- **セット用サムネイル設定（自動軽量化）**: セット編集画面でサムネイル画像をアップロード（またはドロップ）すると、解像度を長辺最大 320px に縮小して軽量な **WebP** 形式へ自動変換し、セット一覧・呼び出し画面・カードに表示できます（画像からセットを読み込んだ場合も自動で軽量サムネを設定します）。
- 保存先は `ComfyUI/user/anima_set_studio/sets/`（サムネイルは `thumbnails/`、Colab環境では Googleドライブへ自動永続化）。

### 2. イラスト集作成・一括生成
1. 保存済みセットを複数呼び出し（同一セットの複数追加・専用の **`⇅ 並び替え`** 画面でのドラッグ＆ドロップ／`⤒ ↑ ↓ ⤓` 順番入れ替え・セット別枚数指定に対応）。
2. **使わないカテゴリ（共通プロンプトで上書きするカテゴリ）** を選択 → 呼び出した全セットのカードから該当カテゴリ欄が自動で隠れ、生成からも除外されます。
3. 呼び出した特定のセットを選んで、元データを壊さずに **その場限りで一時編集** できます（必要なら上書き保存・別名保存も可能）。
4. **共通LoRA**（例：キャラLoRA）・**共通プロンプト**・**ネガティブプロンプト**・**解像度**・**1セットあたり枚数**・**折りたたみ詳細設定（モデル / CLIP / VAE / Shift / Kサンプラー / 保存名）** を設定。
5. **`[実行]`** ボタン1つで、全セット分のジョブ（共通プロンプト先頭＋各セットの非除外カテゴリ、共通LoRA＋セットLoRA合体、1枚ごとユニークシード）を ComfyUI キューへ一括投入します。

## インストール方法

### 通常の ComfyUI 環境
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/kensisi8/ComfyUI-Anima-SetStudio.git
```
※追加の `pip install` は不要です（Python標準ライブラリ＋ComfyUI組込ライブラリのみ使用）。
※`Select` や `LoRA Manager` ポップアップの全機能を使うため、`Comfyui-Anima-Tools` との併用を推奨します。

### 起動方法
ComfyUI 起動後、画面左下の **`🎨 Anima SetStudio`** ボタンをクリック（またはショートカット **`Alt + S`**）すると専用画面が開きます。
